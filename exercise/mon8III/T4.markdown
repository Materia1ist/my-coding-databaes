下面从“操作到底限制了什么”开始推导，再解释为什么 DP 只需要三个状态。

## 1. 把操作理解成“整堆搬运”

初始时每个位置都有一枚单位：

\[
(1,1,\dots,1).
\]

一次对位置 \(i\) 的操作，会把 \(i-1\)、\(i\)、\(i+1\) 三个位置的数全部合并到 \(i\)：

\[
(\dots,a,b,c,\dots)\longrightarrow(\dots,0,a+b+c,0,\dots).
\]

注意两个性质：

- 数只会整堆移动或者合并，不会拆分；
- 所有位置的总和不变。

因此任何可达序列一定满足

\[
\sum_{i=1}^n p_i=n.
\]

但仅有这个条件显然不够。

---

## 2. 最关键的性质：相邻两个正数

假设最终有

\[
p_i>0,\qquad p_{i+1}>0.
\]

哪些操作会影响这两个位置？

只有以

\[
i-1,\ i,\ i+1,\ i+2
\]

为中心的操作。

如果这些操作至少发生过一次，考虑其中最后发生的一次：

- 最后操作 \(i-1\)，会把 \(p_i\) 清零；
- 最后操作 \(i\)，会把 \(p_{i+1}\) 清零；
- 最后操作 \(i+1\)，会把 \(p_i\) 清零；
- 最后操作 \(i+2\)，会把 \(p_{i+1}\) 清零。

而这已经是最后一次影响它们的操作，被清零的位置之后不可能重新变成正数。

所以，想让最终的 \(p_i,p_{i+1}\) 都是正数，上面四个位置一次操作都不能发生。

这说明位置 \(i,i+1\) 上的两个数从始至终没有动过，因此

\[
p_i=p_{i+1}=1.
\]

进一步，由于没有对 \(i\) 或 \(i+1\) 操作过，所以没有任何数能够跨过 \(i\) 与 \(i+1\) 之间的分界线。

初始时前 \(i\) 个位置的总和是 \(i\)，最终仍然必须是 \(i\)。设

\[
S_i=\sum_{j=1}^i p_j,
\]

那么还必须满足

\[
S_i=i.
\]

于是得到最关键的可达条件：

> 如果 \(p_i,p_{i+1}>0\)，那么一定有
>
> \[
> p_i=p_{i+1}=1,\qquad S_i=i.
> \]

由于 \(p_{i+1}=1\)，也等价于 \(S_{i+1}=i+1\)。

---

## 3. 为什么这个条件也是充分的

最终结论是：

一个非负整数序列 \(p\) 可达，当且仅当：

\[
\sum_{i=1}^n p_i=n,
\]

并且对所有 \(1\le i<n\)，只要 \(p_i,p_{i+1}>0\)，就有

\[
p_i=p_{i+1}=1,\qquad S_i=i.
\]

直观理解如下。

如果相邻两个位置最终都是正数，那么它们就是两个从未移动过的 \(1\)，并且它们将整个区间切成左右两个互不影响的部分：

\[
[p_1,\dots,p_i]\mid[p_{i+1},\dots,p_n].
\]

因为 \(S_i=i\)，左边目标总和正好等于左边初始单位数，右边也同样成立，可以分别构造。

不断按照这种相邻的 \(1\) 切分后，每个剩余区间中，所有正数位置都互不相邻。

此时零位置可以充当缓冲：

- `A 0 0` 可以把整堆 \(A\) 向右移动一步；
- `A 0 B` 可以通过操作中间位置合并成 `0 A+B 0`；
- 对称地也可以向左移动、合并。

因此可以依次把初始的单位堆合并成目标大小，再移动到互不相邻的目标位置。这个结论可以对区间长度进行归纳证明。

所以接下来只需要统计满足上述条件的序列，不必再考虑具体操作顺序。

---

## 4. 从可达条件得到局部转移

从左到右确定 \(p_i\)。

假设已经确定了前 \(i-1\) 个位置，现在考虑 \(p_i\)。

只有三种情况。

### 情况一：\(p_i=0\)

前一个位置是什么都无所谓，直接在末尾添加一个零。

权值乘上

\[
x_i^0=1.
\]

### 情况二：\(p_{i-1}=0,\ p_i=k\ge1\)

前一个位置为零时，当前可以任意选择正整数 \(k\)。

权值需要乘上

\[
x_i^k.
\]

### 情况三：\(p_{i-1}>0,\ p_i>0\)

根据可达条件，只能有

\[
p_{i-1}=p_i=1,
\]

并且加入 \(p_i\) 后，前缀和必须正好为 \(i\)。

除此以外的相邻正数全部不合法。

---

## 5. DP 状态

定义

\[
F_{i,s}
\]

表示：

前 \(i\) 个位置满足可达条件，并且

\[
p_1+\cdots+p_i=s
\]

时的权值和。

这里的权值是

\[
\prod_{j=1}^i x_j^{p_j}.
\]

另外定义

\[
Z_{i,s}
\]

表示 \(F_{i,s}\) 中满足 \(p_i=0\) 的部分。

因为在任意合法的前 \(i-1\) 项后面添加一个零都合法，所以

\[
Z_{i,s}=F_{i-1,s}.
\]

还要处理相邻的两个 \(1\)。定义

\[
U_i
\]

表示满足以下条件的前缀权值和：

- 长度为 \(i\)；
- 元素和正好为 \(i\)；
- 最后一项 \(p_i=1\)。

只有这样的前缀，才能在后面继续添加一个相邻的 \(1\)。

---

## 6. 当前正数且前一个位置为零

固定位置 \(i\)，假设当前前缀和为 \(s\)。

如果选择

\[
p_i=k\ge1,
\]

那么前 \(i-1\) 项的和为 \(s-k\)，并且 \(p_{i-1}=0\)。

贡献为

\[
x_i^kZ_{i-1,s-k}.
\]

把所有 \(k\ge1\) 相加，定义

\[
G_{i,s}
=
\sum_{k=1}^{s}x_i^kZ_{i-1,s-k}.
\]

直接计算每个 \(G_{i,s}\) 会多一层枚举，复杂度达到 \(O(n^3)\)。

观察：

\[
\begin{aligned}
G_{i,s}
&=x_iZ_{i-1,s-1}
+x_i^2Z_{i-1,s-2}
+\cdots\\
&=x_i\left(
Z_{i-1,s-1}
+x_iZ_{i-1,s-2}
+x_i^2Z_{i-1,s-3}
+\cdots
\right).
\end{aligned}
\]

括号中除了第一项，后面的部分正好是 \(G_{i,s-1}\)，因此

\[
G_{i,s}
=
x_i\left(Z_{i-1,s-1}+G_{i,s-1}\right).
\]

这样每个 \(G_{i,s}\) 可以 \(O(1)\) 算出。

---

## 7. 完整转移

对于 \(F_{i,s}\)，共有三部分贡献。

第一部分：令 \(p_i=0\)：

\[
F_{i-1,s}.
\]

第二部分：前一个位置为零，当前选择任意正整数：

\[
G_{i,s}.
\]

第三部分：前一个位置和当前位置都是 \(1\)。

这种情况只有在 \(s=i\) 时合法，贡献为

\[
x_iU_{i-1}.
\]

所以

\[
F_{i,s}
=
F_{i-1,s}
+
G_{i,s}
+
[s=i]\cdot x_iU_{i-1}.
\]

这里 \([s=i]\) 表示：若 \(s=i\) 则为 \(1\)，否则为 \(0\)。

---

## 8. 如何更新 \(U_i\)

要求前 \(i\) 项：

- 总和为 \(i\)；
- 最后一项是 \(1\)。

有两种来源。

### 前一个位置是零

前 \(i-1\) 项总和必须是 \(i-1\)，贡献为

\[
x_iZ_{i-1,i-1}.
\]

### 前一个位置也是一

这时必须来自平衡状态 \(U_{i-1}\)，贡献为

\[
x_iU_{i-1}.
\]

所以

\[
U_i=x_i\left(Z_{i-1,i-1}+U_{i-1}\right).
\]

---

## 9. 初始化与答案

空前缀只有一种：

\[
F_{0,0}=1.
\]

为了方便处理第一个位置，可以把空前缀看成“末尾是零”：

\[
Z_{0,0}=1.
\]

没有长度为零且末尾为一的序列：

\[
U_0=0.
\]

最终要求整个序列的总和为 \(n\)，因此答案是

\[
F_{n,n}.
\]

---

## 10. 关于 \(0^0=1\)

当 \(p_i=0\) 时，我们单独使用“添加零”的转移，权值不乘任何东西，也就是乘 \(1\)。

当 \(p_i>0\) 时才会进入 \(G\) 的转移。如果 \(x_i=0\)，这些贡献自然全部为零。

因此代码天然正确处理了 \(0^0=1\)。

---

## 11. 参考代码

```cpp
#include <bits/stdc++.h>
using namespace std;

using int64 = long long;

constexpr int MOD = 1000000007;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int32_t MeloAPIOFe = 0;
    (void)MeloAPIOFe;

    int n;
    cin >> n;

    vector<int> x(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> x[i];
    }

    /*
        f[s]    = 当前的 F_{i-1,s}
        zero[s] = 当前的 Z_{i-1,s}
        nf[s]   = 即将计算的 F_{i,s}
    */
    vector<int> f(n + 1, 0);
    vector<int> zero(n + 1, 0);
    vector<int> nf(n + 1, 0);

    // 空前缀
    f[0] = 1;

    // 将空前缀视为末尾是零
    zero[0] = 1;

    // 当前的 U_{i-1}
    int balancedOne = 0;

    for (int i = 1; i <= n; ++i) {
        /*
            conv 表示当前的 G_{i,s}。

            G_{i,s}
              = x_i * (Z_{i-1,s-1} + G_{i,s-1})
        */
        int conv = 0;

        // 相邻两个 1 的额外贡献 x_i * U_{i-1}
        int adjacentContribution =
            static_cast<int>(1LL * x[i] * balancedOne % MOD);

        for (int s = 0; s <= n; ++s) {
            if (s > 0) {
                int inside = zero[s - 1] + conv;
                if (inside >= MOD) {
                    inside -= MOD;
                }

                conv = static_cast<int>(
                    1LL * x[i] * inside % MOD
                );
            }

            // p_i = 0 的贡献，以及前一项为零、p_i > 0 的贡献
            int value = f[s] + conv;
            if (value >= MOD) {
                value -= MOD;
            }

            // p_{i-1} = p_i = 1，只允许前缀和 s = i
            if (s == i) {
                value += adjacentContribution;
                if (value >= MOD) {
                    value -= MOD;
                }
            }

            nf[s] = value;
        }

        /*
            U_i = x_i * (Z_{i-1,i-1} + U_{i-1})
        */
        int inside = zero[i - 1] + balancedOne;
        if (inside >= MOD) {
            inside -= MOD;
        }

        int newBalancedOne =
            static_cast<int>(1LL * x[i] * inside % MOD);

        /*
            Z_{i,s} = F_{i-1,s}

            交换后：
            zero 保存旧 f，即新的 Z_i；
            f 保存刚算出的 nf，即新的 F_i。
        */
        zero.swap(f);
        f.swap(nf);

        balancedOne = newBalancedOne;
    }

    cout << f[n] << '\n';
    return 0;
}
```

时间复杂度为

\[
O(n^2),
\]

空间复杂度为

\[
O(n).
\]

在 \(n=8000\) 时，大约进行 \(6.4\times10^7\) 次简单转移，可以通过。
