S₀: Initial state (in our case, an empty 3X3 board)
Players(s): a function that, given a state s, returns which player’s turn it is (X or O).
Actions(s): a function that, given a state s, return all the legal moves in this state (what spots are free on the board).
Result(s, a): a function that, given a state s and action a, returns 
a new state. This is the board that resulted from performing the action
 a on state s (making a move in the game).
Terminal(s): a function that, given a state s, 
checks whether this is the last step in the game, 
i.e. if someone won or there is a tie. Returns True if 
the game has ended, False otherwise.
Utility(s): a function that, given a terminal state s,
 returns the utility value of the state: -1, 0, or 1.
